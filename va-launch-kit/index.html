Fill this out once. Your resume, portfolio website and Upwork / OnlineJobs.ph profile drafts are built from it. No experience? That's okay. The Mom Skills Translator and Practice Projects sections are made for you.

The basics
Your niche

Clients don't hire "a VA who does everything." They hire "the VA for people like me." Choose one kind of client to start with. You can change it later.

Services you offer (pick 3–6)
Tools you can use

Only pick tools you've actually used. Free tutorials count if you practiced with the tool. Clients search by tool name, so this matters.

Mom Skills Translator

Running a household is project management. Tick what you've really done. These show up on your resume under Transferable Skills, worded the way clients write job posts.

Work experience

Include office jobs, BPO/call-center work, family business, freelancing, volunteering and school/church roles. Start each bullet with a verb and add a number when you can ("Answered 60+ customer emails a day").

Practice projects / portfolio samples

No clients yet? Make 3 sample projects. Ideas: a cleaned-up inbox folder system (screenshot), a 1-week Canva social media calendar, a lead list in Google Sheets, a travel itinerary, an SOP document. Link each one through Google Drive set to "anyone with the link can view."
